# ¿Es real o fake?

## Descripción general

Desafío educativo orientado a trabajar conceptos introductorios de ciberseguridad mediante una dinámica tipo *Capture The Flag (CTF)*.

Esta descripción es intencionalmente **genérica**: no incluye pasos de resolución ni spoilers. La fundamentación pedagógica completa se encuentra en la documentación del proyecto.
