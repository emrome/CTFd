# Tu primera clave

## Descripción general

Desafío educativo orientado a trabajar conceptos introductorios de ciberseguridad mediante una dinámica tipo *Capture The Flag (CTF)*.

Esta descripción es intencionalmente **genérica**: no incluye pasos de resolución ni spoilers. La fundamentación pedagógica completa se encuentra en la documentación del proyecto.

---

## Clasificación (resumen)

| Atributo | Valor |
|---|---|
| Categoría | Autenticación |
| Subcategoría | Contraseñas |
| Nivel | Fácil |
| Puntaje | 20 |

---

## Dinámica del desafío

El participante debe revisar contenido simulado (p. ej., perfiles o páginas) en un entorno controlado; inspeccionar un archivo adjunto en un entorno simulado y aplicar razonamiento crítico para identificar información relevante y obtener la *flag* (sin incluir spoilers ni pasos de resolución).
